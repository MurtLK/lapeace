# LaPeace

LaPeace is a Sheridan Datathon project about English speech recognition and Mississauga language communities. This website introduces the study, lets visitors inspect its shared reference passage, and explains the sources and limits.

Audience: datathon judges, residents and civic-service teams. Primary action: explore the project on the homepage. The Open dashboard action opens the teammate's full Mississauga Unheard workspace at `/dashboard`, with a return link to the homepage.

Keep the supplied LaPeace logo and navy, blue and teal palette. Use Apple Design from the connected UI Skills MCP for clear hierarchy, immediate feedback, readable typography and accessible settings. Use Cursor's Unslop skill for concrete, plain copy. Preserve the reference passage verbatim.

The Speech Accent Archive contains English recordings from speakers with different first languages. Census home-language counts describe the community, not transcription accuracy. The 311 scenario is a scripted clarification demo. Do not invent results, testimonials, audio or live interactions.
