Analysis settings

Recalculated scores use the cleaned transcript file. Earlier supplied scores remain available.

Case and punctuation are ignored. Digits 3, 5 and 6 are normalized to words. WER = substitutions + deletions + insertions, divided by reference words. WER can exceed 100%.

SER = erroneous reference sections / 4. With punctuation missing, words are aligned to four fixed reference sections; an insertion at a boundary belongs to the following section. This is a reproducible convention, not recovered spoken sentence boundaries.

Audio stays in this session; reattach after reopening. Missing audio is not evidence of silence.

Flags, notes, settings and calculated results are cached locally. Exported backups can transfer them; there is no live team sync.
