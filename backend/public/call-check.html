How this check works, its limits and source code

Press Record a sample, record up to 20 seconds, then stop. ElevenLabs Scribe v2 transcribes the sample. Fixed English keyword rules add points for phrases about codes, unusual payments, remote access and other red flags.

The request score produces No red flags at 0 points, Be careful at 1 or 2, and Likely scam at 3 or more. These are rule labels, not probabilities. A missed phrase, a harmless mention or a transcription error can change the result. The rules match English phrases, not all languages. No red flags does not verify the caller.

Voice score, recording use and source code

The optional voice model compares acoustic features with real recordings and built-in macOS voices used in its training. It was not trained on modern neural voice clones. Its score does not decide the request verdict or prove who is calling.

Live checking needs a connected backend with an ElevenLabs key. A sample goes to ElevenLabs for transcription. If enabled, the local voice check writes a temporary file and deletes it after processing. This app does not keep a recording history; this is not a statement about the transcription provider's retention.
